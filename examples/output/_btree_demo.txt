B-tree: pack many keys per node so the tree stays short and fat

  Every node holds up to 2t-1 keys and all leaves sit at the same depth, so the tree can
  never degenerate. Overflow splits a node and pushes its median up; underflow borrows from
  a sibling or merges. With hundreds of keys per node, a billion-row index is three seeks
  deep -- which is why B-trees index essentially every database on earth.
