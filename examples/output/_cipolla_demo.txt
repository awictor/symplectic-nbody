Cipolla's algorithm: modular square roots via GF(p^2)
========================================================
solve x^2 = n (mod 37) by working in the field GF(37^2)
pick a with a^2 - n a non-residue, then x = (a + w)^((p+1)/2), w^2 = a^2 - n

Both algorithms return valid roots (possibly differing by sign). Cipolla needs
no case analysis on the powers of 2 dividing p-1, so it shines when that power
is large -- one exponentiation in a 2-dimensional field and the root drops out.
