Mann-Whitney U test -- nonparametric, rank-based, outlier-robust
================================================================

Group A ~5.4, Group B ~6.6 (clear shift):
  U = 0.0, effect size P(A>B) = 0.000, p = 0.00001 (exact)
  t-test p = 0.00000  (both detect the shift)

Add one wild outlier (50.0) to group A:
  Mann-Whitney p = 0.00055 (exact) -- still sees B > A
  t-test        p = 0.48324 -- outlier inflates A's mean, masks the shift
  The rank test uses only order, so one outlier moves it by a single rank.
