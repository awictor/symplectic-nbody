Kendall tau -- rank correlation from concordant vs discordant pairs
====================================================================

Monotone but CURVED relationship (y ~ exp):
  Kendall tau-b = 0.993  (p = 4.02e-12)
  Pearson r     = 0.946   (linear measure, underrates the monotone link)

Outlier robustness (add one wild point to a clean linear trend):
  Pearson r : 0.988 -> 0.075  (crashes)
  Kendall t : 0.947 -> 0.864  (barely moves -- ranks ignore magnitude)

Pair breakdown for the curved data (25 points, 300 pairs):
  concordant = 299, discordant = 1, x-ties = 0, y-ties = 0
  tau = (C - D) / pairs = (299 - 1) / 300 = 0.993
