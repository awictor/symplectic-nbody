Dirichlet convolution: the arithmetic functions as a ring

  the classical identities (all verified exactly on 1..40):
    mu * 1  = epsilon   :  True
    phi * 1 = id        :  True
    1 * 1   = d (divisors): True
    id * 1  = sigma     :  True
    mu * id = phi       :  True

  standard arithmetic functions:
       n   mu  phi   d  sigma
       1    1    1   1      1
       2   -1    1   2      3
       6    1    2   4     12
      12    0    4   6     28
      30   -1    8   8     72
      36    0   12   9     91

  Mobius inversion: recover f from its divisor sums F = f * 1, via f = F * mu
    f(n) = n^2;  F = divisor sums;  F(12) = 210
    recovered f(12) = 144 (should be 144): True
    full recovery exact: True

  This is the discrete fundamental theorem of calculus: 1 and mu are inverse under
  convolution, so divisor-summing and Mobius-inverting undo each other.
